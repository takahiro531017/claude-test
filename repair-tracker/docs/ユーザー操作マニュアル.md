# ユーザー操作マニュアル(現場担当者向け)

パソコン・タブレット・スマートフォンのどれでも使えます。倉庫ではスマホかタブレットが便利です。

---

## 1. ログインのしかた(最初の1回)

1. 管理者から**招待メール**が届きます。メール内のリンクを開きます。
2. **パスワードを決めます**(12文字以上。他のサービスと同じものは使わないでください)。
3. スマホの**認証アプリ**(Google Authenticator または Microsoft Authenticator)を入れ、画面のQRコードを読み取ります。表示された**6桁の数字**を入力して登録完了です。
4. 2回目以降は「メールアドレス+パスワード」→「認証アプリの6桁」の順で入ります。

- 30分操作しないと**自動でログアウト**されます。入力途中のものは保存してから席を離れてください。
- 使い終わったら右上の「ログアウト」を押してください。共用パソコンでは必ずログアウトを。
- スマホを機種変更した/パスワードを忘れた → 管理者(本社情報システム)に連絡してください。

---

## 2. 修理品を受け付ける(預かり)

1. 上のメニュー「**新規受付**」を押します。
2. 次を入力します(* は必須)。
   - 販売店名*(入力すると候補が出ます)、担当者名、連絡先
   - メーカー*(プルダウン)、商品名*、型番(候補が出ます)、**シリアル番号**
   - 購入日、保証書の有無、保証期間内/外、付属品(チェック)
   - 故障症状*、外観の状態メモ(傷・汚れなど)
3. **シリアル番号**を入れて次の欄に移ると、同じ番号がすでに登録されている場合に**黄色い警告**が出ます。二重受付でないか確認し、問題なければ「重複でないことを確認した」にチェックします。
4. **写真**: 「ファイルを選択」を押すと、スマホならカメラが起動します。外観・シリアルのラベル・付属品を撮影してください(1枚10MBまで、最大20枚)。
5. **エンドユーザー(お客様)の情報は、販売店の情報で足りるなら入力しないでください。** 必要な場合のみ、氏名・電話・住所を入力します(暗号化して保存されます)。
6. 「**受付を保存して管理番号を発行**」を押します。
7. 管理番号(例 `FUK-20261008-001`)が発行されます。「**預り証を印刷する**」から印刷、またはPDFで保存できます(預り証にお客様の個人情報は載りません)。

> 管理番号は「拠点コード-日付-連番」です。電話・メールで問い合わせるときは、この番号を伝えてください。

---

## 3. 進み具合を更新する(ステータス変更)

修理品の行(管理番号)を押して詳細画面を開きます。

- 画面上の**大きな青いボタン「次へ進める → ○○」**を押すと、次の工程に進みます。
  預かり → メーカー発送済 → メーカー修理中 → メーカーから返却受領 → 販売店へ返送済 → 完了
- 工程に合わせて、**メーカー発送日・送り状番号・メーカー受付番号・見積金額・修理内容・返却日・返送の送り状番号**などを入力し、「**変更を保存**」を押します(発送日などは、ボタンを押した日が自動で入ります。違う日なら直してください)。
- 間違えて進めた → 「その他:」の欄から**1つ前の工程に戻す**ことができます。
- 一時的な状態は「その他:」から選びます:**保留 / 見積確認待ち / 修理不能・返品 / キャンセル**。
- 「変更コメント」欄に理由を書くと、履歴に残ります(例「集荷依頼済み」)。
- いつ・誰が・何から何へ変えたかは、画面下の**ステータス変更履歴**に残ります。

> 完了にした案件を元に戻すことは、管理者だけができます。

---

## 4. 写真を追加する

詳細画面の「写真・添付」で「写真を追加」を押します(スマホはカメラが開きます)。画像(JPEG/PNG/WebP)かPDFだけ、10MBまでです。誤って追加した写真は「削除」できます。

---

## 5. 探す(検索・絞り込み)

「**修理品一覧**」を開きます。
- 検索欄に、**管理番号・販売店名・型番・シリアル番号・送り状番号・メーカー受付番号**のどれかを入れると探せます(一部でも可)。
- 拠点・ステータス・メーカー・受付日の期間で絞り込めます。「**滞留のみ**」にチェックすると、遅れている案件だけが出ます。
- 並び替え(更新が新しい順など)と、「**カンバン表示**」(工程ごとに並べた表示)の切り替えができます。
- 行の左に**オレンジの線**と「⚠」が出ているものは**滞留**(例:メーカー発送後14日を超えた、返却受領後7日を超えても販売店へ返送していない)です。早めに確認してください。
- 自拠点以外の案件は、権限のない人には表示されません(本社の閲覧権限の人は全拠点が見えます)。

---

## 6. お客様の氏名・電話・住所を見る(マスク解除)

- 一覧や詳細では、個人情報は**伏せ字**で表示されます(例:`山田 ○○` / `090-****-1234`)。
- 本当に必要なときだけ、詳細画面の「**🔓 表示する**」を押します(自拠点の「拠点担当」と管理者のみ)。
- 表示した内容は**60秒で自動的に隠れます**。「今すぐ隠す」でも隠せます。
- ⚠ **「表示する」を押した記録(誰が・いつ・どの案件を)は、すべて保存されます。** 業務に必要なときだけ使ってください。画面のスクリーンショット・写真・メモへの書き写しは避けてください。
- 修正は「編集」から行います。

---

## 7. 同時に開いている人がいるとき

- 同じ案件を別の人が開いていると、「👥 ○○さんもこの案件を開いています」と出ます。
- 自分が編集している間に他の人が保存すると、「**○○さんが△時△分に更新しました**」と出ます。
  - **あなたの入力はまだ消えていません。** 内容を見比べて、「最新を読み込む」を押してから、必要な変更をやり直してください。
- 他の人の更新は、画面を再読み込みしなくても自動で反映されます(右上に「● リアルタイム」)。

---

## 8. 困ったとき

| こうなった | こうする |
|---|---|
| 「権限がありません」と出る | 他拠点の案件や、権限のない操作です。必要なら管理者へ依頼 |
| 「他のユーザーが先に更新しました」 | 7章のとおり、最新を読み込んでからやり直す |
| 認証アプリの数字が通らない | スマホの時刻が「自動設定」になっているか確認 |
| 間違えて案件を作った | 詳細画面の「この案件を削除」(拠点担当・管理者)。削除済みは管理者が復元できます |
| それ以外 | 管理者(本社情報システム)へ。**画面に出た文言と時刻**を伝えてください(お客様の個人情報は伝えない) |

## 9. 守ってほしいこと
- パスワード・認証アプリの数字を、他人に教えない・メモに残さない。
- 離席するときは画面を閉じるかログアウトする。
- 個人情報を、チャット・メール・紙のメモに書き写さない。
