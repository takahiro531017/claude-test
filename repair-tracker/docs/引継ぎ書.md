## 6. 開発を引き継ぐ人へ

- 最初に読む順: `README.md` → `docs/セキュリティ設計書.md` → `supabase/migrations/`(DB設計の本体)→ `src/lib/status.ts`(ステータス規則)。
- 変更前に `npm run lint && npm run typecheck && npm test && npm run test:db && npm run test:e2e` がすべて通ることを確認する。CI でも同じものが走る。
- 技術は標準的なもの(React / TypeScript / PostgreSQL / Supabase)のみで、特定のAIサービスやベンダー独自のコードに依存していません。Claude/AI の API は**実行時に一切使っていません**。
- ベンダー乗り換え: データは `pg_dump` と CSV で全件出力可能(運用マニュアル§6)。暗号化された個人情報を読むには鍵(`PII_KEYS`)の引き継ぎが必須。
