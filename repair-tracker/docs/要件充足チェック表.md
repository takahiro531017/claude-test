# 要件充足チェック表

凡例: **○** = 実装済みで自動テスト等により確認 / **△** = 実装済みだが実環境(Supabase)では未確認、または一部制限あり / **×** = 未実装

> **全体の注意**: この開発環境には Docker・Deno・Supabase がなく、実際の Supabase 上での動作確認はできていません。
> DB(RLS・トリガー・監査・バックアップ)は実PostgreSQL 16で、Edge Functions は Deno/Supabase の偽物で、画面はブラウザ(Playwright)+モックAPIで検証しています。
> 「△」は主にその理由です。本番公開前に README の「公開後の確認」を実環境で実施してください。
