# VENUSiS Instagram 運用レポート｜操作マニュアル

Instagramアカウントの成果を、毎月かんたんに確認するためのページです。
Meta Business Suite から書き出したCSVファイルを読み込むだけで、次の3つが分かります。

1. **今月の成果は良かったか**（前の期間と比べてどうか）
2. **どの投稿が良かったか**（投稿の種類・曜日・時間帯）
3. **次に何をすればいいか**（データから自動で作られた文章）

> 専門知識は必要ありません。難しい言葉は、ページ内の「この数字の意味」や「数字の意味」に説明があります。

## 安心してお使いいただくために

- 読み込んだデータは **この端末のブラウザの中だけ**で処理・保存されます。外部のサーバーには送信されません。
- Instagramのパスワードやアクセストークンなどは一切使いません。
- 同じパソコン・同じブラウザで開くと、前回のデータが残っています。別の端末では、もう一度CSVを読み込む必要があります。

---

## 1. はじめて開いたとき

画面の上に **「サンプルデータです」** と表示されていれば、見えている数字はすべて見本（架空のデータ）です。
実際のCSVを読み込むと、自動で本物のデータに切り替わります。

## 2. CSVを書き出す（Meta Business Suite）

1. パソコンのブラウザで **Meta Business Suite**（business.facebook.com）を開き、Instagramアカウントを選びます。
2. 左のメニューから **「インサイト」→「コンテンツ」** を開きます。
3. 右上で、書き出したい **期間** を選びます（初回は「過去6か月」など長めがおすすめ。毎月の更新では「先月1日〜今日」など）。
4. **「データをエクスポート」**（または「エクスポート」）を押し、形式で **「CSV」** を選んでダウンロードします。

※ 画面の名前はMeta社の更新で変わることがあります。「インサイト」の中で、CSVで書き出せる場所を探してください。
※ **リーチ** と、**いいね・コメント・シェア・保存** の列が入っていると、すべての分析ができます。

## 3. CSVを読み込む

1. このページの一番下の近くにある **「データ入力」** までスクロールします（画面上の「CSVを読み込む」ボタンからも移動できます）。
2. **「CSVを選ぶ」** を押して、ダウンロードしたファイルを選びます（パソコンでは、ファイルをドラッグしても読み込めます）。
3. 「○件を読み込みました」と表示されれば完了です。上のグラフや表が、自分のデータに変わります。

- Excelで保存し直した文字化けしやすいファイル（Shift_JIS）も、自動で判定して読み込みます。
- **同じ投稿を何度読み込んでも大丈夫です。** 「投稿日時」と「キャプション（文章）」が同じ投稿は、1つにまとまり、数字は新しい方に更新されます。
- 投稿を1件だけ追加したいときは、「投稿を1件ずつ入力する」から入力できます。

## 4. 結果の見かた

| 場所 | 見るポイント |
| --- | --- |
| **今月の成果** | 4つの数字と、前の期間との比較。**▲**は増えた、**▼**は減った、**―**は変化なし。 |
| **気づき** | 自動で作られた文章。「次にやること」が、次の投稿へのヒントです。 |
| **月ごとの推移** | 月別のリーチ（棒）と、反応率（折れ線）。右肩上がりかどうかを見ます。 |
| **投稿タイプ別** | リール・フィード・ストーリーズのどれが届きやすく、反応されやすいか。 |
| **いつ投稿すると届きやすいか** | 色が濃い枠ほど、その曜日・時間帯の投稿が多くの人に届いています。点線の枠は1件だけのデータで、参考程度です。 |
| **投稿ランキング** | 良かった投稿の一覧。「リーチ順」「エンゲージメント率順」「保存数順」で並べ替えられます。 |

**期間の切り替え**（直近30日／90日／180日／全期間）で、見る期間を変えられます。
「前の期間」とは、選んだ期間と同じ日数だけ前の期間です（例：直近30日なら、その前の30日）。基準日は、データの中でいちばん新しい投稿の日です。「全期間」のときは比較をしません。

## 5. 毎月の更新手順（目安：15分）

ページの下の「毎月やること」に、同じ内容のチェックリストがあります（月が変わると自動でリセットされます）。

1. CSVを書き出す（上の「2」）
2. このページにCSVを読み込む（上の「3」）
3. 「今月の成果」と「気づき」を確認する
4. 「投稿ランキング」で、良かった投稿を3つ確認する
5. 次の月の投稿テーマと、投稿する曜日・時間帯を決める

## 6. よくあるエラーと対処

| 表示・症状 | 原因と対処 |
| --- | --- |
| 「**必要な列が見つかりませんでした**」と出て、列を選ぶ画面が出る | CSVの列名が想定と違います。画面の指示に従い、「公開日時（日付）」と「リーチ」にあたる列を選んで「この内容で読み込む」を押してください。 |
| 「**読み込める投稿がありませんでした**」 | 日付やリーチが空のファイルです。CSVの期間や種類（投稿のインサイト）をご確認ください。 |
| 「**読み取れなかった行が○行ありました**」 | 日付やリーチが空・不正な行です。その行だけ飛ばして、ほかは読み込まれています。 |
| 「CSVに見つからなかった項目: ○○」 | その列がCSVにありません。無い列は0として計算します（投稿タイプが無いときは、すべて「フィード」扱い）。保存やシェアの列が入るように書き出し直すと、より正確になります。 |
| 文字化けしている | 通常は自動で直ります。直らないときは、Excelで開いて「CSV UTF-8」で保存し直してください。 |
| 数字が合わない・少ない | 選んでいる**期間**を確認してください（「全期間」にすると全件になります）。 |
| ストーリーズが「時間帯」のグラフに出ない | 仕様です。ストーリーズは24時間で消えるため、時間帯の分析から除いています。 |
| 時間帯のグラフが空、または「深夜」に偏る | CSVに時刻が無い（日付だけ）と、時間帯の分析はできません。時刻つきで書き出してください。 |
| 前回のデータが消えた | ブラウザの履歴・サイトデータを削除すると消えます。「データをCSVで保存（バックアップ）」でこまめに保存し、消えたらそのファイルを読み込み直してください。 |
| 間違えてデータを削除した | 元に戻せません。バックアップCSV、またはMetaから書き出したCSVを読み込み直してください。 |

## 7. 用語のかんたん説明

- **リーチ**：投稿を見た「人数」（同じ人が何度見ても1人）。
- **エンゲージメント率**：見た人のうち、反応した人の割合。（いいね＋コメント＋シェア＋保存）÷ リーチ。投稿ごとに計算した率の平均です。
- **保存率**：見た人のうち、保存した人の割合。「役に立つ」と思われたサインです。
- **リール／フィード／ストーリーズ**：短い動画／通常の写真・カルーセル投稿／24時間で消える投稿。
