# SNS分析アプリ(Instagram)

SNS運用代行の会議で、**毎回新しいデータを足しながら**使い続けられる分析アプリです。
Instagramのインサイトから書き出した **Excelファイルを、そのまま読み込める**ので、手で数字を打つ必要はありません。
数字は消えずにたまり、翌月分を足すと「前回比」が自動で出ます。ボタン1つで **PDF・HTML・Excel** の分析ファイルが作れます。

* 専門用語には必ず「用語 → 意味」の矢印説明が付きます(画面・PDF・Excel共通)。
* 良し悪しは **色と矢印**(<span style="color:#2f855a">↑ 増えた</span> / <span style="color:#c53030">↓ 減った</span> / → ほぼ同じ)で分かります。
* 数字が無い項目は、推測せず **「データなし」** と表示します。

![ホーム画面](docs/img/01_home.png)

---

## 1. はじめに(最初の1回だけ)

1. **Python 3.10以上** をインストールします(<https://www.python.org/>)。
2. このフォルダ(`sns-analytics`)でターミナル(Windowsは「コマンドプロンプト」)を開き、次の2行を実行します。

```
pip install -r requirements.txt
python -m playwright install chromium
```

2行目は **PDFを作るための部品**を入れる操作です(数分かかります)。

## 2. 起動する(毎回これ1行)

```
streamlit run app.py
```

自動でブラウザが開きます(開かないときは <http://localhost:8501> を開く)。

最初の画面で、クライアント名を入れて「クライアントをつくる」を押します。
`sample/` フォルダに **Instagram 2026年9月分のインサイトのファイル(5種類)** が入っているので、「サンプルのファイルを読み込む」を押すと、すぐ全部の画面を試せます。

> 会議で使うときは、ブラウザの画面をそのままZoom/Teamsなどで共有してください。スマホでも見られます。

---

## 3. 毎回の会議の流れ(3ステップ)

```
 ┌─────────────────────┐    ┌──────────────────────┐    ┌────────────────────┐
 │ ① 新しいデータを追加   │ →  │ ② 画面を共有して説明  │ →  │ ③ 分析ファイルを作る │
 │ インサイトのExcelを   │    │ ホーム/深掘り5ページ  │    │ PDF・HTML・Excel   │
 │ まとめて選ぶ          │    │ (矢印と色で一目で)   │    │ ボタン1つ           │
 └─────────────────────┘    └──────────────────────┘    └────────────────────┘
      数字はたまっていく            前回との比較は自動            過去分も一覧から再ダウンロード
```

### ① 新しいデータを追加する

左のメニュー **「➕ 新しいデータを追加」** → **「① ファイルで追加」** を開き、インサイトのファイルを **まとめて** 選びます。

![データ追加画面](docs/img/02_add.png)

次の5種類のファイルに対応しています(1か月分ずつ書き出したものを想定)。

| ファイル | 読み取る中身 |
|---|---|
| フォロワーチャート | フォロワー数、フォロワー増減、新規フォロワー、フォロー数、投稿した本数(種類別) |
| エンゲージメントの推移 | インプレッション、リーチ、いいね、コメント、保存、動画再生 |
| プロフィールインサイトチャート | プロフィールビュー数、ウェブサイト/テキスト内リンク/メール/電話/道順のタップ数 |
| フォロワーの年齢 | 年齢ごとの女性・男性の人数 |
| フォロワーの性別 | 女性・男性の人数 |

* **種類・アカウント名・期間は自動で見分けます**(中身の列名と、ファイル名の `アカウント名_20260901-20260930` の部分から)。違っていたら画面で直せます。
* 取り込む前に、読み取れた日数・エラー・読み取らなかった列が表示されます。
* **同じ日に同じ数字が既にあるときは、今ある数字を変えません**(空欄だけ埋めます)。上書きしたいときだけ「ファイルの数字で上書きする」を選びます。**過去のデータが勝手に消えることはありません。**
* 翌月分は、同じ5つのファイルを同じ手順で追加するだけです。

そのほかの入口
* **「② 1日ぶんを手入力」**: 数字を1日ぶんだけ直接入れるとき。入力欄に例が出ます。必須は日付・アカウント名・フォロワー数。空欄は「データなし」になります。
* **「③ 会議メモ」**: 今回決まったこと・次にやること。分析ファイルの最後に載ります。

### ② 画面を共有して説明する

| メニュー | 使いどころ |
|---|---|
| 🏠 ホーム | 今回のまとめ(3行)、数字の変化(↑↓→)、フォロワー推移、このデータの読み方 |
| 🔎 深掘り 5ページ | **フォロワー / 反応(エンゲージメント率) / リーチ・インプレッション / プロフィール・リンク / フォロワーの属性(年齢・性別)** を1ページずつ。各ページは「用語の説明 → グラフ+一言コメント → 考えられる理由」の順 |
| 🖼 投稿した日の分析 | 反応が良かった日ベスト3 / 少なかった日ワースト3(理由の仮説つき)、種類別・曜日別・時間帯別 |
| ⏪ 過去との比較 | **前回 / 1か月前 / 3か月前** と今回を並べて表示、日ごと・月ごとの推移 |

![深掘りページ](docs/img/03_deep.png)

* 左の **「今回の月」** を変えると、過去の月を「今回」として見直せます。
* 複数のクライアントは、左上の **「クライアント」** で切り替えます(＋で追加)。データはクライアントごとに分かれます。
* 「理由」は数字から考えた **仮説** です。断定ではなく、会議で話し合うきっかけとして使ってください。

### ③ 分析ファイルを出す

**「📄 分析ファイルを作る」** → ボタンを1回押すと、PDF・HTML・Excel が作られます。

![分析ファイル](docs/img/04_report.png)

* 同じ画面の下に **過去に作ったファイルの一覧** が出て、いつでも再ダウンロードできます。`output/` フォルダにも保存されます。
* 中身: ① 今回のまとめ3行 ② 数字の変化(前回比・1か月前比・3か月前比) ③ ベスト3/ワースト3と理由の仮説 ④ 種類別・曜日別・時間帯別 ⑤ フォロワー推移 ⑥ 深掘り5ページ ⑦ 次にやること(改善提案3〜5個) ⑧ このデータの読み方 ⑨ 用語集
* 見本は `sample/sample_report.pdf` / `sample_report.xlsx` です。

## 4. このデータについて知っておくこと(大事)

インサイトのファイルの性質上、次の点があります。レポートの「このデータの読み方」にも自動で載ります。

* **フォロワー数** は「その日のはじめの人数」です(翌日の数字との差が、その日の増減と一致するため)。月末の人数は「最終日の数字 + 最終日の増減」で計算します。実際の人数はInstagramアプリで確認してください。
* **リーチ・インプレッション・いいね・コメント・保存** は「その日に投稿した分の合計」です。**投稿1本ずつの数字や、投稿した時刻は入っていません**。そのため「投稿ごとのベスト3」ではなく「投稿した日ごとのベスト3」、「時間帯別」は「データなし」になります。
* リーチは日ごとの数字を足しているので、別の日に同じ人が見ていても重ねて数えます。
* **シェア** のデータが無いため、エンゲージメント率は「いいね+コメント+保存 ÷ リーチ」で計算します。
* ストーリーズは投稿した本数だけで、見られた回数などは「データなし」です。
* 1か月分だけのときは、前回・1か月前・3か月前は「データなし」になります。来月分を足すと矢印つきで比べます。

## 5. 間違えたとき・直したいとき

**「🛠 データの確認・修正・削除」** を開きます。表の数字を直して **「変更を保存」** で修正できます。
消したい行は **「削除」にチェック → 「本当に削除する」にチェック → 「変更を保存」** です(元には戻せません)。

## 6. 保存場所とバックアップ

* 数字はすべて `data/sns.db` に保存され、アプリを閉じても残ります。
* **バックアップは `data/sns.db` をコピーするだけ**です。別のパソコンに移すときも、このファイルを同じ場所に置きます。
* 作った分析ファイルは `output/` にあります。

## 7. 困ったとき

| こんなとき | 対処 |
|---|---|
| PDFが作れない | `python -m playwright install chromium` をもう一度実行。HTMLとExcelは作られているので、先にそちらを使えます。 |
| 「データなし」が多い | その数字がファイルに入っていません。 |
| 前回比が「データなし」 | 比べる相手の月のデータがありません。月ごとにファイルを追加してください。 |
| ファイルの種類が分からないと出る | 列名がいつもと違います。画面の「種類」を選び直してください。それでも読めないときは列名を教えてください。 |

## 8. 数字の見方の約束

* エンゲージメント率 → 見た人のうち、いいね・コメント・保存などをした人の割合(反応の合計 ÷ リーチ)です。
* 矢印: ±2%以内は「→ ほぼ同じ」、それより増えれば ↑、減れば ↓ です。割合の差は「pt(ポイント)」で表します(3.0%→3.5% = +0.5pt)。
* 数字の良い目安は、画面の **「📖 用語集」** にあります(業種や規模で変わるため、あくまで目安です)。

## 開発者向けメモ

```
sns-analytics/
├─ app.py                # 画面(Streamlit)
├─ requirements.txt
├─ snsapp/
│  ├─ db.py              # SQLite保存(1行=1日。属性・会議メモ・出力履歴)
│  ├─ importer.py        # Excel/CSVの種類判定・列の対応づけ・取り込み
│  ├─ metrics.py         # 日ごと → 月ごとの集計、比較の相手探し
│  ├─ analysis.py        # まとめ・仮説・改善提案の文章づくり
│  ├─ charts.py          # SVGグラフ(画面とPDFで共通)
│  ├─ report.py          # HTML / PDF / Excel 出力
│  ├─ glossary.py        # 用語集(矢印説明の元データ)
│  └─ style.css
├─ templates/report.html # 画面・レポート共通の部品
├─ data/                 # sns.db(自動作成・git管理外)
├─ output/               # 作成した分析ファイル(git管理外)
└─ sample/               # インサイトのExcel(2026年9月分)と見本レポート
```

* 環境変数 `SNS_DATA_DIR` / `SNS_OUTPUT_DIR` で保存先を変えられます。
* 対応SNSは現在 Instagram のみです(DBには `sns` 列があります)。
