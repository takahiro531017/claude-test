# 返品商品 一元管理システム

家電問屋のPB商品の返品(リサイクル販売・廃棄・メーカー返品)を、スマホ入力+受付票(A5)印刷で一元管理するWebアプリです。
全体計画は [`../docs/returns-system/PLAN.md`](../docs/returns-system/PLAN.md) を参照してください。

> **現在の実装範囲:フェーズ1(MVP)**。プリンタ設定画面・サーバー直接印刷・処分別の管理項目・マスタ管理画面はフェーズ2、
> ダッシュボード・CSV・メーカー別返送リスト・バックアップはフェーズ3で追加します。完全な操作マニュアルはフェーズ3で整備します。

## セットアップ(開発・確認用)

```bash
cd returns-system
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/seed_sample.py --reset             # ダミーデータ40件(任意)
python run.py                                     # http://localhost:8000
```

Windows では `start.bat` をダブルクリックでも起動します(初回に自動で環境を作ります)。

- スマホから使うには、同じWi-Fiで `http://<サーバーPCのIPアドレス>:8000` を開きます(Windowsはファイアウォールの許可が必要な場合があります)。
- データは `data/` フォルダ(DB・写真)に保存されます。場所は環境変数 `RETURNS_DATA_DIR` で変更できます。
- 受付票のQRに入るURLの元になる「ベースURL」は、環境変数 `RETURNS_BASE_URL`(例 `http://returns.local:8000`)で指定します。未指定のときは、アクセスしたアドレスが使われます。**IPアドレスが変わると貼付済みの受付票のQRが開けなくなるため、本番ではルーターでIPを固定し、ベースURLを設定してください。**(設定画面はフェーズ2)

## テスト

```bash
pip install -r requirements-dev.txt
python -m pytest
```

## フェーズ1でできること

| 機能 | 場所 |
|---|---|
| 担当者の選択(端末に記憶) | `/staff` |
| 返品の受付登録(必須は品番・数量・不良内容。下書き自動保存・前回引き継ぎ・保存して次を入力・写真縮小) | `/new` |
| 品番・返品元・メーカー・不良内容の候補表示と自動蓄積(表記ゆれの自動正規化。品番で商品名が違えば警告) | 受付登録時に自動 |
| 受付票(A5・QR付き)のブラウザ印刷/PDF、A4に2枚並べる切り取りモード | `/print/<受付番号>` |
| 未印刷の受付票のまとめて印刷、再印刷 | `/print-queue` |
| 一覧・検索・絞り込み、滞留日数の強調(7日で黄、14日で赤) | `/returns` |
| 詳細(QRの飛び先)・状況更新・処分方法の選択・履歴・内容の追記修正 | `/r/<受付番号>` |
| 受付番号での検索(`5` と入れると今日の005) | ホーム |

状況は「受付済 → 確認中 → 処分決定済 → 完了」を1段階ずつ進めます(1つ前に戻すことも可)。
「処分決定済」「完了」へ進むには処分方法の選択が必要です。処分別の入力項目と、完了条件のチェックはフェーズ2で追加します。
