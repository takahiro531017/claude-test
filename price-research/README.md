# 家電 競合価格調査アプリ（price-research）

家電の品番・メーカー名・商品名から、価格・発売時期・競合を比較する社内ツール。
**現在は Phase 1（雛形・検索UI・正規化・モックデータ表示）です。** 表示データはすべて架空のモックで、実在の商品・価格ではありません。

## セットアップ
```bash
cd price-research
npm install
cp .env.example .env   # Phase 2 以降で APIキーを設定（.env はコミットしない）
npm run dev            # http://localhost:3000
npm test               # 正規化・検索・価格計算のテスト
npm run lint           # 型チェック
```

## Phase 1 の動作確認
http://localhost:3000 で次の3パターンを検索し、候補一覧→詳細→競合比較（暫定）に進めます。
- 品番: `SE-WD100`（`ＳＥ－ＷＤ１００` / `se wd100` も同一扱い）
- メーカー＋カテゴリ: `サンプル電機 洗濯機`
- 商品名: `ドラム式洗濯乾燥機`

取得できない項目（中古価格・送料・ポイント・後継機など）は「取得不可」と表示します。推測値は表示しません。

## ディレクトリ
- `src/lib/normalize/` 表記ゆれ正規化（全角半角・ハイフン・大小文字・メーカー日英表記・カテゴリ語）
- `src/lib/search.ts` 検索・スコアリング（Phase 2 でアダプター結果に置換）
- `src/lib/mock/` 開発用モックデータ
- `src/app/` 画面（検索 / 商品詳細 / 競合比較 / 履歴）と `api/search`
